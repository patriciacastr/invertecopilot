# Datos

## `pdfs/` — fichas técnicas y estudios de ejemplo (documentos públicos)
Consigue 3 o 4, idealmente uno escaneado:
- Banco de Inversiones (consulta pública) del MEF: busca por CUI y descarga el documento técnico registrado (ficha técnica o perfil).
- Ejemplos de formatos y guías en mef.gob.pe (sección de formatos y fichas técnicas sectoriales).
- Si ya trabajas con proyectos en tu consultoría: usa solo documentos que sean públicos, sin datos personales.

Anota para cada archivo: CUI, entidad, tipo (FTS / FTE / baja y mediana complejidad / perfil), si es escaneado, URL de origen.

## `corpus/` — normativa (5 a 10 documentos)
Ver `docs/corpus.md`. Guarda la **versión y fecha** de cada norma.
